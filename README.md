# يومي — Android APK

Built with KTAI Agent 🤖

- **الحزمة**: com.ktai.yawmi
- **المحتوى**: التطبيق مدموج بالكامل داخل الـ APK (يعمل بدون إنترنت)

## التحميل
افتح صفحة **Releases** في هذا المستودع وحمّل `app-release.apk`، ثم ثبّته على جهازك
(فعّل «تثبيت التطبيقات من مصادر غير معروفة» عند الطلب).

## البناء يدويًا
المشروع يتُبنى تلقائيًا عبر GitHub Actions عند كل push. لبنائه محليًا:

```bash
gradle assembleRelease
```
